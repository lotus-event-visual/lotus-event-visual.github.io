01結論

結論から申し上げます。売上の倍化は狙える水準です。ただし「人を出す量」を増やすだけでは届きません。増やす売上の半分以上を、直受注の一式案件と毎月入る売上でつくる設計に切り替えます。

提言 1

チーフを 5人前後 → 10〜12人へ

次の現場の機材を倉庫で先に触る。トラブルを倉庫で再現する。月1回は必ずプロセッサー席に座る。この3つで、5〜8年かかる育成を3年に縮めることを狙います。

提言 2

直受注の一式案件を 年4〜6件 → 年40件へ

機材+設営+当日の映像責任者をまとめてお受けします。取引先のお客様は取りません。取引先が入っていない領域だけを取りにいきます。

提言 3

毎月入る売上を 年1,200万円つくる

常設LEDの年間保守、会場の定期オペ、機材の預かり・検品。人工の繁閑の波を平らにする「底」をつくります。

土台は2つです。 ①常勤の事務担当(以下「毎日事務」)1名。見積の当日返し、実績と請求の突き合わせ、未収の管理を担います。②月次の損益と資金繰りを毎月同じ形で見ること。AIは、見積・営業・請求に寄せます。

今月、最初に動かす3手

  1. 主要な取引先との役割分担と条件を、書面で確認する口頭の取り決めを1枚にまとめ、行き違いをなくします。
  2. 新設会場へ、増設LEDとオペの応援を小さく提案する既存のお付き合いの中で、ご紹介をお願いする形で進めます。
  3. 段位表と手当の幅を決める初段からチーフまでの5段。入社時に見せられる形にします。

03現状診断

売上は2期続けて約1.14億円で横ばい。営業利益率は約17%から約7%へ下がりました。人員への投資が先に進み、売上の伸びがまだ追いついていない段階です。

売上と営業利益率(3期)

販管費は約1,000万円増えました。中心は人件費です。賃借料と外注費は減っています。2024年3月期は税込経理、2025年3月期からは税抜経理です。

いまの稼ぎ方
  • 収益源は2つ。技術スタッフの日当(人工)と、LEDなど機材のレンタルです。
  • 主戦場はドーム・アリーナのツアーと大型イベント。
  • 受注の入口は、既存の14窓口が中心です。
  • LEDの直受注は年4〜6件にとどまります。
  • 事務が常勤の体制になっておらず、見積・請求・手配が社長とチーフに集まっています。

強み・弱み・機会・脅威

強み
  • ドーム・アリーナ級の現場を回してきた経験
  • 最新のLED・プロセッサーの運用力
  • 倉庫で検品を担ってきた経験
  • AIで資料・HP・動画を内製できる体制
弱み
  • チーフが5人前後にとどまる
  • 制作・主催との直接の接点が薄い
  • 協力会社として入る案件が中心で、価格を自社で設計できる案件が少ない
  • 事務が常勤の体制になっていない
機会
  • ライブ市場は2025年に8,564億円(前年比12.6%増)。2035年に1兆1,000億円の見通し
  • 首都圏で新しいアリーナ・ホールの開業が続く
  • 業界の技術者は平均53.4歳。若手を早く育てられる会社が採用で勝つ
脅威
  • 特定の取引先への売上の集中
  • 人件費・交通費の上昇
  • 大型施設は大手メーカーが機材を一括納入する
  • 事故1件で信用を失う業態

なぜ売上が止まったか(なぜを5回)

  1. 利益が減った人員への投資が先に進み、売上が増えなかった。
  2. 売上が増えない人工の売上は「人数×日数×日当」で上限があり、日当を決めるのは上流。
  3. 値決めできない制作・主催から直接ではなく、協力会社として入る案件が中心。
  4. 上流から直接頼まれない「丸ごと任せれば安心」と言っていただくための、チーフ・提案書・実績の見せ方・窓口がそろっていない。
  5. チーフが足りない育成が現場任せで、一人前まで5〜8年かかる前提のまま。
診断の結論:根本の原因は「チーフの数」と「上流に届く営業の仕組み」の2つです。この計画は、資源をこの2つに集中させます。

よくあるトラブルを倉庫で再現し、入力→プロセッサー→出力の順に切り分ける練習をします。月2回から。

10AI投資

AIへの投資は続ける価値があります。ただし、これまでの使い道はHP・マニュアル・動画に偏っていました。次の90日で、売上に直結する「見積・営業・請求」へ入れ替えます。

  1. 見積の当日返し過去の見積・機材表・単価表から下書き。社長は金額だけ承認します。
  2. 実績と請求の突き合わせシフトと見積・請求を照らし、差を自動で拾います。
  3. 営業メールと提案書一社ごとに書き分けます。送信は社長の承認後です。
  4. 安全体制シートと実績集の更新資格の期限管理も含めます。
  5. 育成の教材と、倉庫の再現練習の稽古表
  6. 補助金・助成金の申請書の下書き

続けるかの判定(毎月)

社長・チーフの時間を月10時間以上浮かせたか。受注に1件以上つながったか。2か月続けてどちらも満たさない契約は止めます。

AIに単独で決めさせないこと

安全・電源・法務・発注・価格・勤怠・社員の評価。この7つは必ず人が決めます。

12リスクと撤退基準

大きなリスクは「既存の取引先との信頼を損なうこと」と「増収に伴う運転資金の増加」の2つです。どちらも、売上を追う前に手を打てます。

リスク兆し打ち手止める・引く線
既存の取引先との信頼先方のお客様から直接のお声がけがあった直受注は「取引先が入っていない領域」だけ。声がかかったら先に相談取引先から懸念が出たら、その領域の営業を止めて話し合う
増収に伴う運転資金の増加入金前の給与・外注払いが重なる人件費・外注費3か月分の残高を目標にし、月次の資金繰り表で先に見る残高が2か月分を切ったら採用・広告を止める
チーフ候補の離職・燃え尽き報告や相談が減る、表情や口数が変わる課題は1現場1つ、週1の短い報告だけ、段位と手当を先に見せる担当が抜ける前に、代わりの人の実演を済ませる
現場の事故(落下・通電)同じ種類のヒヤリハットが続く外す前のロック確認、段ごとの点灯、電源・荷重は仕様書と責任者で決める事故は1件でも作業を止め、原因と手順を見直す。同じ種類のヒヤリハットが2回出たら標準手順を改める
新規事業への時間の分散社長の営業時間が週5時間を切る他事業は週3時間まで。運転はAIに「続ける基準」を3か月満たさない事業は止める

13次の意思決定

計画を動かすために、まず次の4点を決めます。どれも1行で決められる形にしてあります。

  1. 段位表の手当の幅初段からチーフまでの5段。金額の幅だけ決めれば、入社時に見せられます。
  2. 毎日事務の進め方募集が先か、今の体制で1か月の当番の試しが先か。
  3. 一人ひとりの「次の3か月」面談で、今の段と次に積む経験を決めます。
  4. 広告・営業代行の上限額31日目から使う月額の上限。
