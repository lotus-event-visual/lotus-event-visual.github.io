LOTUS VISUAL JOURNAL / LOTUS VISUAL を知る #05

LOTUS VISUAL の 1 日。
搬入から撤去まで、誰が何をしているか

客席から見える本番は、1 日のうちのほんの一部です。
その前後に、映像チームは何をしているのか。LOTUS VISUAL の技術提供の流れを、朝から夜までの時間軸でたどります。

01 / BEFORE THE DAY前日まで:読み合わせ

LOTUS VISUAL の 1 日は、会場に着く前に始まっています。進行表、会場の図面、機材の構成——この三つを読み合わせて、「誰が何を担当するか」「何をいつ受け取るか」を決めるのが、前日までの仕事です。当サイトの「技術提供」のページでは、この段階を「素材と進行、機材と担当をそろえる」と書いています。

読み合わせで確かめるのは、派手なことではありません。上映する最終データはいつ届くのか。合図を出すのは誰か。会場の電源はどの系統か。搬入口の幅と、作業できる時間帯。そして、現場責任者と各担当の連絡系統。未決定の項目があれば、「誰が、いつまでに決めるか」だけを揃えておきます。

当日の速さは、前日の読み合わせの深さで決まる。

この段階は、お客様から見ると地味です。けれど、本番で映像が一度も止まらない日は、たいていこの読み合わせが丁寧だった日です。

02 / LOAD-IN朝:搬入と設営

会場に入ると、まず機材を所定の位置へ運びます。LED パネル、プロセッサー、スイッチャー、ケーブル。搬入の順番は、会場の搬入経路と他のセクション(舞台・音響・照明)の作業順序に合わせます。映像チームだけが速くても、現場は速くなりません。

設営の核心は「つないで、映して、本番の状態へ」です。担当機材を設置し、配線し、入力から画面までの表示を一つずつ確かめる。表示先、素材の見え方、音声の受け渡しを、リハーサルの前に揃えておきます。

止める条件

当サイトの技術提供のページには、こう書いてあります。「機材の支え方・電源・作業条件が合わない場合は、作業を進めず責任者と調整します」。設営は、速さより先に、この一文が守られているかで評価されます。

ここで次の担当へ引き継ぐ条件は一つ。「指定した画面に映像が届き、その状態を次の人へ渡せること」。これが満たされて初めて、設営は終わりです。

03 / REHEARSAL昼:リハーサルと合図

リハーサルで合わせるのは、映像の中身ではなく「合図」です。素材の順番、切り替えのタイミング、誰の声で次へ進むのか。進行担当の合図で切り替えるのか、登壇者の決まった言葉をきっかけにするのか。これを合わせないまま本番に入ると、映像は「正しいのに、遅い」状態になります。

変更が出たときの連絡方法も、ここで決めます。素材が差し替わったら誰に伝わるのか。進行が延びたら、映像は待つのか、止めるのか、どこから再開するのか。予備機があるなら、切り替えを担当する人は誰か。異常時は、事前に決めた待機画面と連絡手順に沿って動けるように、手順を一度なぞっておきます。

04 / SHOW本番:応える

本番中の映像担当の仕事を一言で言えば、「進行に応える」ことです。当サイトでは、技術のつながりを「読み解く → 組み立てる → 応える → 届ける」の四つで説明しています。本番はこの三つ目と四つ目です。担当ポジションで送出と操作を行い、出力と客席からの見え方を確かめ続ける。

本番中にいちばん大事なのは、「変更はその場で共有する」ことです。素材、進行、機材構成に変更があれば、関係する担当へすぐ伝える。現場責任者と各担当の連絡系統が揃っていれば、指示の行き違いは減ります。映像チームは、画面を見ているだけでなく、この連絡の輪の中にいます。

本番を支えるのは、操作の腕前より、作業の間のコミュニケーション。

05 / STRIKE夜:撤去と引き渡し

終演後、客席の照明が上がってからが、もう一つの山場です。撤去は、作業順序に沿って進めます。撤去開始の合図、退出時刻、搬出車両と他セクションの動き。映像チームだけが先に片付けると、照明や音響の作業の邪魔になることがあります。

引き渡すのは、機材だけではありません。数量、付属品、機材の状態、返却先、そして残る確認事項。破損や不足が見つかれば、その場で責任者へ共有します。「数だけ合っていればいい」ではなく、次に使う人が困らない状態で返す。倉庫に戻った機材は、リストと機材番号で照合され、状態の違うものは正常品と混ぜずに担当者へ渡されます。

ここまでが、LOTUS VISUAL の 1 日です。本番の数時間のために、前日の読み合わせから、翌日の倉庫の照合まで。客席からは見えない時間のほうが、ずっと長い。

LOTUS VISUAL の仕事の形

LOTUS VISUAL の技術提供は、この 1 日のすべてを頼んでいただく必要はありません。「仕込みだけ」「本番だけ」「撤去だけ」「倉庫の準備だけ」——必要な工程から、現場のチームに加わります。機材のレンタルだけのご相談も、技術提供と組み合わせたご相談も、どの工程からでも伺います。

映像制作、音響・照明の運用、会場の電気工事や吊り設備の施工は、技術提供に自動的に含まれるものではありません。必要な作業と担当会社を、事前に分けて整理します。

今日の持ち帰り

  1. 1 日は前日に始まっている。進行表・会場図・機材構成の読み合わせが、当日の速さを決める。
  2. 設営の終わりは「映ったとき」ではなく「渡せるとき」。次の担当へ状態ごと引き継げて、初めて終わり。
